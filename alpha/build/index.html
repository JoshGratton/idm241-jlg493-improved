Triggers

  • Hover on
  • Hover off
  • Click

Rules

Star button

  • Hover on: cursor changes to a glove and the top of the button moves down 3 pixels
  • Hover off: glove changes to a cursor and the button moves back up 3 pixels to its original position
  • Click: the top part of the button moves down 8 pixels, then back up 8 pixels when released; the START tag hides and a popover opens under the button, growing from small to full size
  • Click Star button again or click anywhere on the page: the popover closes and the START tag returns

Popover START +10 XP button

  • Hover on: cursor changes to a glove and the text changes to a lighter blue
  • Hover off: glove changes to a cursor and text changes back to its original blue

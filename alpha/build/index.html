Form basic sentences

Lesson 1 of 4

Triggers

  • Hover on
  • Hover off
  • Click

Rules

Lesson button

  • Hover on: button presses down slightly
  • Hover off: button goes back up
  • Click: button presses all the way down, comes back up, and a popover opens under it

Popover START button

  • Hover on: text changes color
  • Hover off: text changes back

Feedback

  • See: button moves down and up, popover appears, text changes color
  • Hear: none
  • Feel: none

Loops & Modes

Loops

  • START tag floats up and down until the button is clicked

Modes

  • Popover open: START tag is hidden; the button can still be hovered and clicked
  • Popover closed: clicking the button again or anywhere else closes it and the START tag returns

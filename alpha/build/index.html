Lesson 1 of 6

Triggers

  • Hover on
  • Hover off
  • Click
  • Click outside the popover

Rules

Star button

  • Hover on: cursor changes to a pointer and the top of the button moves down 3 pixels
  • Hover off: cursor changes back and the button moves back up 3 pixels to its original position
  • Click: the button moves all the way down (8 pixels), then back up when released; the START tag hides and a popover opens under the button, growing from small to full size
  • Click again or click anywhere else on the page: the popover closes and the START tag returns

Popover START +10 XP button

  • Hover on: cursor changes to a pointer and the text changes to a darker blue
  • Hover off: text changes back to its original blue

Feedback

See

  • Star button hover on: cursor turns into a hand and the button sinks slightly as its bottom edge gets thinner
  • Star button hover off: cursor turns back into an arrow and the button rises back up
  • Star button click: the button pushes all the way down and pops back up, the START tag disappears, and the popover grows open under the button
  • Click again or anywhere else: the popover disappears and the START tag reappears
  • START +10 XP hover on: cursor turns into a hand and the text turns darker blue
  • START +10 XP hover off: the text turns back to its original blue
  • START tag floating up and down above the button

Hear

  • None

Feel

  • None

Loops & Modes

Loops

  • START tag floats up and down 7 pixels continuously while the popover is closed
  • Hovering on and off the star button can repeat endlessly

Modes

  • Popover closed (default): START tag is floating
  • Popover open: START tag is hidden; the star button can still be hovered and clicked

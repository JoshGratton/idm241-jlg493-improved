Duolingo Button Microinteraction!

1. Original Interface

  • Duolingo: https://www.duolingo.com
  • Microinteraction: the lesson button on the Learn path

2. Locating the Object

First time using Duolingo

  1. Go to duolingo.com and click Get Started.
  2. Pick the language you speak (site language at the top of the page).
  3. Pick the language you want to learn.
  4. Answer the setup questions: why you're learning, how much you already know, and your daily goal.
  5. When the first lesson / knowledge test opens, click the X in the top left to exit it.

Finding the button

  1. Go to the Learn tab in the left sidebar.
  2. On the path map, find the circle with the floating START tag above it.

3. Triggers

  • Hover on
  • Hover off
  • Click

4. Rules

Lesson button

  • Hover on: button presses down slightly
  • Hover off: button goes back up
  • Click: button presses all the way down and a popover opens under it

Popover START button

  • Hover on: text changes color
  • Hover off: text changes back

5. Feedback

  • See: button moves down and up, popover appears, text changes color
  • Hear: none
  • Feel: none

6. Loops & Modes

Loops

  • START tag floats up and down until the button is clicked

Modes

  • Popover open: START tag is hidden; clicking anywhere else closes the popover
  • Locked lessons (gray): no START tag and can't be clicked into

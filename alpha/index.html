Duolingo Button Microinteraction!

Button coming soon! :D

Original Interface

https://www.duolingo.com/learn

  1. Sign in and go to the Learn tab in the left sidebar.
  2. Stay on the path map with the circles and the dots connecting them.
  3. Find the current lesson: the blue circle with the floating START tag.

Triggers

  1. Landing into the site: when it loads, there's a floating START tag above the next unlocked lesson. The user doesn't have to do anything.
  2. Hovering the lesson button: the cursor turns into a pointer and the button presses down slightly.
  3. Moving off the button: the button goes all the way back up to its original position.
  4. Clicking the button: the button goes all the way down and a popover appears under it.
  5. Hovering the popover's START button: its text changes color.

Rules

  1. Only the next lesson gets the START tag. The tag appears over the current, unlocked lesson only. It floats up and down while the user does nothing and goes away once the button is pressed.
  2. The button's height follows the cursor. It is fully raised when resting, pressed down slightly when hovered, and pushed all the way down when clicked. If the cursor leaves before clicking, it always goes back to resting.

Feedback

  1. See: the START tag floating, the cursor turning into a pointer, the button pressing down as its darker bottom edge shrinks, the green popover appearing with the lesson name and a START button, and that button's text changing color on hover.
  2. Hear: nothing. The path map is silent; Duolingo saves its sounds for inside the lesson.
  3. Feel: no vibration on desktop, but the thick bottom edge disappearing makes the button feel like a real button being pushed into the page.

Loops & Modes

Loops

  1. Idle loop: the START tag floats up and down forever until the button is pressed.
  2. Hover loop: hovering on and off can repeat endlessly; the button goes down and back up every time.
  3. Lesson loop: after a lesson is finished, the START tag moves to the next circle and the microinteraction starts again there.

Modes

  1. Locked: gray circles further down the path have no START tag and can't be started yet.
  2. Completed: finished circles change color and offer practice instead of a new lesson.
  3. Popover open: the START tag is hidden while the popover is open; clicking elsewhere closes it and the button goes back up.
  4. Touch: phones have no hover, so a tap goes straight to the pressed state.

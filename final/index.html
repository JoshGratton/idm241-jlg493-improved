Final Description

Apple iPhone Feature Panel Microinteraction

1. Original Interface

  • https://www.apple.com/iphone-18-pro/
  • Improving: the feature pills, the up and down arrow buttons, the color dots and the Close (×) button in the iPhone 18 Pro “Take a closer look” panel, plus a new Play/Pause button and a new “Take a closer look” button

What Apple does now

  • Clicking a feature pill grows it into a card with a description, the image changes to match, and the card that was open shrinks back into a feature pill
  • Once a card is open, its + disappears, so there is no clear way to close the card
  • The up and down arrow buttons step through the features, and the up arrow button is dimmed when the first feature is open
  • Nothing shows how many features there are or which number is open
  • Features only change when the user clicks

Why it’s an improvement

  • Autoplay steps through every feature with a progress bar, so the user sees all 7 features without clicking 7 times
  • The + rotates into a × on the open card, so it’s clear how to close the card and see the full phone
  • A counter (“2 of 7”) shows where the user is
  • The Play/Pause button keeps the user in control of autoplay
  • The “Take a closer look” button reopens the panel on the last open feature and chosen color, so the user picks up where they left off

2. Triggers

Feature pills

  • Hover on
  • Hover off
  • Click

Up and down arrow buttons

  • Hover on
  • Hover off
  • Click

Color dots

  • Hover on
  • Hover off
  • Click

Play/Pause button

  • Hover on
  • Hover off
  • Click

Close (×) button

  • Hover on
  • Hover off
  • Click

“Take a closer look” button

  • Hover on
  • Hover off
  • Click

3. Rules

Feature pills

  • Hover on:
    • Cursor changes to a glove
    • The feature pill’s background fades from dark gray to a lighter gray over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The background fades back to dark gray over 0.2 seconds
  • Click a closed feature pill:
    • The open card shrinks back into a feature pill over 0.4 seconds and its × rotates back into a +
    • The clicked feature pill grows into a card over 0.4 seconds
    • Its + rotates 45° into a × over 0.3 seconds
    • The description text fades in over 0.3 seconds after the card finishes growing
    • The image fades out and the new feature’s image fades in, zooming from 105% to 100% over 0.5 seconds
    • The counter changes to that feature’s number, for example from “1 of 7” to “2 of 7”
    • Only one card can be open at a time
    • The open feature is saved to the database
    • Autoplay stops and the Play/Pause button changes from ❚❚ to ▶
  • Click the × on the open card:
    • The card shrinks back into a feature pill over 0.4 seconds and its × rotates back into a +
    • The description text fades out
    • The image fades back to the full phone over 0.5 seconds
    • The counter fades out
    • Autoplay stops and the Play/Pause button changes from ❚❚ to ▶

Up and down arrow buttons

  • Hover on:
    • Cursor changes to a glove
    • The arrow fades from gray to white over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The arrow fades back to gray over 0.2 seconds
  • Click the down arrow button:
    • The next feature pill opens into a card, the same way as clicking a closed feature pill
    • Autoplay stops and the Play/Pause button changes from ❚❚ to ▶
  • Click the up arrow button:
    • The previous feature pill opens into a card, the same way as clicking a closed feature pill
    • Autoplay stops and the Play/Pause button changes from ❚❚ to ▶
  • When the first feature is open:
    • The user cannot go back before the first feature
    • The up arrow button fades to 30% opacity over 0.2 seconds
    • The cursor does not change to a glove on the up arrow button
    • Clicking the up arrow button does nothing
  • When the last feature is open:
    • The user cannot go past the last feature
    • The down arrow button fades to 30% opacity over 0.2 seconds
    • The cursor does not change to a glove on the down arrow button
    • Clicking the down arrow button does nothing

Color dots

  • Only shown when the Colors card is open:
    • The color dots appear under the Colors description
  • Hover on:
    • Cursor changes to a glove
    • A thin white ring fades in around the color dot over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The ring fades away over 0.2 seconds, unless that color dot is selected
  • Click:
    • The white ring moves to the clicked color dot
    • The phone image fades to the new color over 0.4 seconds
    • The color name changes, for example from “Shown in Burgundy” to “Shown in Silver”
    • Autoplay stops and the Play/Pause button changes from ❚❚ to ▶
    • The chosen color is saved to the database

Play/Pause button

  • Hover on:
    • Cursor changes to a glove
    • The button’s background fades from dark gray to a lighter gray over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The background fades back to dark gray over 0.2 seconds
  • Click while playing (❚❚):
    • Autoplay stops
    • The progress bar on the open card stops where it is
    • The icon changes from ❚❚ to ▶
  • Click while paused (▶):
    • Autoplay starts again
    • The progress bar keeps filling from where it stopped
    • The icon changes from ▶ to ❚❚
    • If no card is open, the first feature pill opens into a card

Close (×) button

  • Hover on:
    • Cursor changes to a glove
    • The button’s background fades from dark gray to a lighter gray over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The background fades back to dark gray over 0.2 seconds
  • Click:
    • The panel fades out and shrinks to 95% over 0.3 seconds
    • Autoplay stops
    • The “Take a closer look” button fades in where the panel was

“Take a closer look” button

  • Hover on:
    • Cursor changes to a glove
    • The button fades from blue to a darker blue over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The button fades back to blue over 0.2 seconds
  • Click:
    • The button fades out over 0.2 seconds
    • The panel fades in and grows from 95% to 100% over 0.3 seconds
    • The last open feature and chosen color are loaded from the database
    • The panel opens on the last open feature, with the phone shown in the chosen color
    • Autoplay starts and the Play/Pause button shows ❚❚

5. Loops & Modes

Loops

  • While autoplay is on, a white progress bar fills along the bottom of the open card over 5 seconds, then the next feature pill opens into a card and the progress bar starts again
  • After the last feature, autoplay goes back to the first feature and keeps repeating until the user clicks a feature pill, an arrow button, a color dot, the Play/Pause button or the Close (×) button

Modes

  • Autoplay mode (default when the panel opens):
    • Features change on their own every 5 seconds
    • The progress bar shows on the open card
    • The Play/Pause button shows ❚❚
  • Manual mode (after clicking a feature pill, an arrow button, a color dot or Pause):
    • Features only change when the user clicks
    • The progress bar is hidden
    • The Play/Pause button shows ▶
  • Colors mode (while the Colors card is open):
    • The color dots appear under the Colors description
    • In every other card, the color dots are hidden

6. Visuals

Each frame shows one state, with the cursor where the mouse would be.

Beta Description

Nike Add to Bag Microinteraction

1. Original Interface

  • https://www.nike.com/t/air-force-1-07-mens-shoes-jBrhbr/CW2288-111
  • Improving: the shoe size buttons, the Add to Bag button, a new View Bag link and the Bag icon on the Nike shoe page

What Nike does now

  • Hovering a size or selecting a size both give it a darkened (black) border, so the selected size and sizes hovered on look the same
  • The Add to Bag text never changes, so it doesn’t show which size is being added to the user's bag
  • Clicking Add to Bag with no size selected: “Select Size” turns red, the size grid gets a red outline and “Please select a size.” appears under the grid; nothing moves
  • Clicking Add to Bag with a size: the page dims/ has a grey overlay and an “Added to Bag” panel covers the top right corner until the user closes it

2. Triggers

Shoe size buttons

  • Hover on
  • Hover off
  • Click

Add to Bag button

  • Hover on
  • Hover off
  • Click

View Bag link

  • Hover on
  • Hover off
  • Click

3. Rules

Size buttons

  • Hover on: cursor changes to a glove and the size button’s border changes from light gray to black
  • Hover off: glove changes to a cursor and the border changes back to light gray
  • Click: the size button fills black over 0.2 seconds and its text turns white; any other selected size goes back to white; the Add to Bag text changes from “Add to Bag” to “Add to Bag – M 10”; if the error is showing, “Select Size” turns back to black, the red outline goes away and “Please select a size.” disappears
  • Sold-out size: the button is light gray with a line through the size, the cursor does not change to a glove, and clicking it does nothing

Add to Bag button

  • Hover on: cursor changes to a glove and the button changes from black to gray
  • Hover off: glove changes to a cursor and the button changes back to black
  • Click with no size selected: the button shakes left and right 6 pixels, 3 times, over 0.4 seconds; “Select Size” turns red; the size grid’s outline flashes red once, then stays red; “Please select a size.” appears in red under the size grid
  • Click with a size selected: a lighter gray bar fills the button from left to right over 0.6 seconds and the text changes to “Adding…”; the shoe is saved to the user’s bag; a small shoe thumbnail arcs from the button up to the Bag icon over 0.6 seconds; the button text changes to “✓ Added” and a View Bag link appears under the button for 2 seconds, then the button changes back to “Add to Bag – M 10” and the link disappears
  • While “Adding…” or “✓ Added” is showing: clicking the button does nothing

View Bag link

  • Hover on: cursor changes to a glove and the link’s underline disappears
  • Hover off: glove changes to a cursor and the underline comes back
  • Click: the Bag page opens

Bag icon

  • When the shoe thumbnail lands: the Bag icon grows 20% and shrinks back over 0.3 seconds, and the number on the icon goes up by 1
  • The bag count is saved, so it is still there after the page is refreshed

5. Loops & Modes

Loops

  • Add to Bag shakes left and right 3 times each time it is clicked with no size selected
  • “✓ Added” and the View Bag link show for 2 seconds, then the button changes back to “Add to Bag – M 10”

Modes

  • No size selected: clicking Add to Bag shows the error (shake, red “Select Size”, red outline and “Please select a size.”) instead of adding the shoe
  • Size selected: the Add to Bag text changes to “Add to Bag – M 10” and clicking it adds the shoe
  • Adding: the button is locked until “✓ Added” changes back

6. Visuals

Each frame shows one state, with the cursor where the mouse would be.

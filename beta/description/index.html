Beta Description

Nike Add to Bag Microinteraction

1. Original Interface

  • https://www.nike.com/t/air-force-1-07-mens-shoes-jBrhbr/CW2288-111
  • Improving: the size buttons, the Add to Bag button and the Bag icon on a Nike shoe page

Why it’s an improvement

  • When a user forgets to pick a size, Nike shows a small red “Please select a size” message that’s easy to miss. The new version shakes the button and highlights the size grid so the user knows exactly where to look.
  • When a shoe is added, Nike shows a popup that covers the page. The new version shows the shoe flying into the Bag icon, so the user gets confirmation and can keep shopping.

2. Triggers

Size buttons

  • Hover on
  • Hover off
  • Click

Add to Bag button

  • Hover on
  • Hover off
  • Click

Bag icon

  • Shoe thumbnail lands on the icon

3. Rules

Size buttons

  • Hover on: cursor changes to a glove and the size button’s border changes from light gray to black
  • Hover off: glove changes to a cursor and the border changes back to light gray
  • Click: the size button fills black and its text turns white; any other selected size goes back to white; the Add to Bag text changes from “Add to Bag” to “Add to Bag – M 10”; if the “Please select a size” message is showing, it disappears
  • Sold-out size: the button is light gray with a line through the size, the cursor does not change to a glove, and clicking it does nothing

Add to Bag button

  • Hover on: cursor changes to a glove and the button changes from black to dark gray
  • Hover off: glove changes to a cursor and the button changes back to black
  • Click with no size selected: the button shakes left and right 6 pixels, 3 times, over 0.4 seconds; the size grid’s border flashes red once; “Please select a size” appears in red above the size grid
  • Click with a size selected: a lighter gray bar fills the button from left to right over 0.6 seconds and the text changes to “Adding…”; the shoe is saved to the user’s bag; a small shoe thumbnail arcs from the button up to the Bag icon over 0.6 seconds; the button text changes to “✓ Added” for 2 seconds, then changes back to “Add to Bag – M 10”
  • While “Adding…” or “✓ Added” is showing: clicking the button does nothing

Bag icon

  • When the shoe thumbnail lands: the Bag icon grows 20% and shrinks back over 0.3 seconds, and the number on the icon goes up by 1
  • The bag count is saved, so it is still there after the page is refreshed

5. Loops & Modes

Loops

  • Each time Add to Bag is clicked with a size selected, the full sequence plays again (fill, fly, grow, “✓ Added”) and the bag number goes up by 1 each time
  • Each time Add to Bag is clicked with no size selected, the shake and red flash play again

Modes

  • No size selected: clicking Add to Bag shows the error instead of adding the shoe
  • Size selected: clicking Add to Bag adds the shoe
  • Adding: Add to Bag can’t be clicked until “✓ Added” changes back

6. Visuals

Each frame shows one state, with the cursor where the mouse would be.

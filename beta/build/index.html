Rules

Shoe size buttons

  • Hover on:
    • Cursor changes to a glove
    • The shoe size button’s border fades from light gray to black
  • Hover off:
    • Glove changes back to a cursor
    • The border fades back to light gray
  • Click:
    • The shoe size button fades from white to black over 0.2 seconds and its text turns white
    • Any other selected shoe size button fades back to white
    • The “Add to Bag” button text changes from “Add to Bag” to “Add to Bag – M 10”
    • If the error is showing, “Select Size” turns back to black, the red outline fades away and “Please select a size.” disappears
  • Sold-out shoe size button:
    • The button is light gray with a line through the size
    • The cursor does not change to a glove
    • Clicking it does nothing

“Add to Bag” button

  • Hover on:
    • Cursor changes to a glove
    • The button fades from black to gray over 0.2 seconds
  • Hover off:
    • Glove changes back to a cursor
    • The button fades from gray back to black over 0.2 seconds
  • Click with no shoe size selected:
    • The shoe cannot be added until a shoe size is selected
    • The button shakes left and right 6 pixels, 3 times, over 0.4 seconds
    • “Select Size” turns red
    • A red outline flashes once around the shoe size buttons, then stays red
    • “Please select a size.” appears in red under the shoe size buttons
  • Click with a shoe size selected:
    • A lighter gray bar fills the button from left to right over 0.6 seconds and the text changes to “Adding…”
    • The shoe is added to the user’s bag in the database, and the new bag count is saved
    • A small shoe thumbnail arcs from the button up to the Bag icon over 0.6 seconds
    • When the shoe thumbnail lands, the Bag icon grows 20% and shrinks back over 0.3 seconds, and the number on the Bag icon goes up by 1
    • The button text changes to “✓ Added” and the “View Bag” link appears under the button
    • After 2 seconds, the button text changes back to “Add to Bag – M 10” and the “View Bag” link disappears
  • While “Adding…” or “✓ Added” is showing:
    • Clicking the button does nothing

“View Bag” link

  • Hover on:
    • Cursor changes to a glove
    • The link’s underline disappears
  • Hover off:
    • Glove changes back to a cursor
    • The underline comes back
  • Click:
    • The Bag page opens
